DIH Command Manual

Every chat command in DIH Client, what it does and how to use it. . commands are the client's own; # commands drive the integrated Baritone pathfinder and AI.

1. The basics

DIH has two command systems, both typed in normal chat:

PrefixSystemLists commandsNotes
.DIH client commands.commands, .helpNever sent to the server. Prefix can be changed with .prefix.
#Integrated Baritone + AI#helpPathfinding, mining, seed tools, AI. Prefix is the Baritone prefix setting.
  • Default . prefix: . — or % when Meteor Client is also installed (Meteor already owns .). The prefix can be any of . % - _ * # @ & =.
  • Tab completion works on every argument: module names, macro names, item/block ids, packet class names, slot names, player names, waypoints.
  • Typing a command with no arguments prints its usage.
  • .help <command> shows the description and aliases of any . command. #help <command> prints the full built-in help of any # command (click it in #help to open).
  • ^toggledih (typed in chat as-is) turns the whole client on or off.
  • Panic / hide mode: while the client is hard-locked by panic hide, all DIH commands are swallowed silently (under any prefix) so nothing leaks to the server.
  • Lite builds ship without: setting, irc, matchmaking, multi, toggle, modules, oresim, ghostblock, friend, waypoints, gamemode, fakegm, xcarry, rv, namescrape.
  • Addons can register more . commands. If an addon's command name collides with an existing one it is registered as <addonId>:<name> instead.

2. Reading this manual

  • <arg> — required, [arg] — optional, a|b — pick one, … — any number of words.
  • Examples use the default . prefix — substitute yours if you changed it.
  • State words. Wherever a command takes on|off|toggle, the client accepts on/enable/true/1, off/disable/false/0, and toggle. Leaving it out toggles.

3. Client (.) commands

3.1 Help & info

.help [command]

With no argument, prints every command with its one-line description. With a command name (or alias), prints that command's description and aliases.

.help
.help macro

.commands — alias .cmds

Compact comma-separated list of every registered command and the current prefix.

.modules — alias .features

Lists every installed module name (built-in and addon).

.oresim

Diagnostic report for OreSim (the Xray module's ore predictor): whether Xray is on, its mode and style, the seed it is using (or why it's invalid/missing), the scope the seed is saved under, how many ore families are selected, the local worldgen status, chunks simulated, and how many nearby real ores match. Use it when OreSim isn't drawing anything.

3.2 Modules & settings

.toggle <module> [on|off|toggle] — alias .t

Turns a module on, off, or flips it.

.toggle killaura
.t scaffold on
.t freecam off

.setting <module> [key] [value…] — alias .set

Reads or writes any module setting without opening the ClickGUI.

FormEffect
.setting <module>List every setting of the module with its current value.
.setting <module> <key>Print one setting.
.setting <module> <key> <value…>Set it. Use reset or default as the value to restore the default.

Module names with spaces can be written with - (e.g. storage-esp).

.setting xray
.set xray mode
.set killaura range 4.2
.set killaura range reset

.friend [add|remove|clear] [name] — alias .team

Manages the friends/teams list used by combat and ESP modules.

FormEffect
.friendShow the friend list.
.friend add <name>Add a player (tab-completes online players).
.friend remove <name>Remove a player.
.friend clearEmpty the list.

.ghostblock … — alias .gb

Client-side "ghost" blocks that only you can see (controls the GhostBlock module).

FormEffect
.gb toggleTurn the module on/off.
.gb resetRemove every ghost block and restore the real blocks.
.gb creative [on|off|toggle]Fake creative mode — whatever you place becomes a ghost block. Turning it on also enables the module.
.gb blockShow the currently armed block.
.gb block <id>Arm a block for placement (e.g. diamond_block). Enables the module.
.gb block offDisarm (none/reset also work) — held blocks become ghosts again.

3.3 Keybinds & prefix

.bind <key> <command…> / .bind clear <key>

Binds a key to run any chat line — a DIH command, a # command, or plain chat.

.bind G .macro myMacro
.bind H #goto 0 0
.bind clear G

.binds

Lists all command keybinds.

.prefix [new|reset]

Shows, changes or resets the . command prefix. Allowed: . % - _ * # @ & =. reset goes back to the environment default (. or % with Meteor). If Meteor is installed and you pick ., the client keeps % and warns you.

.prefix
.prefix -
.prefix reset
Built-in key defaults (changed in the config, not with .bind): Right Shift opens the module menu, V reloads the stored GUI. Flush queue / clear queue / toggle send / toggle delay / toggle logger are unbound by default.

3.4 Macros

Macros are built in the macro editor (module menu → Macros) or entirely from chat with the subcommands below. They're stored in config/dih/dih_macros.nbt.

Running

FormEffect
.macro <name>Run the macro once.
.macro <name> <times>Run it times times (1–100 000) back to back; each run waits for the previous to finish.
.macro <name> <times> <delayTicks>Same, with delayTicks (0–72 000; 20 ticks = 1 s) between runs.
.macro stopStop every running macro and loop.
.macro stop <name>Stop one macro and its loop.
.macro clearCancel queued loops (the current run is allowed to finish).

Authoring from chat

FormEffect
.macro new <name>Create an empty macro.
.macro add <name> <TYPE> [field=value …]Append an action. TYPE tab-completes from every macro action type. Fields are the action's public fields; enums, booleans, ints, longs, floats, doubles and strings are accepted (no spaces in values).
.macro show <name>List the steps with their indices.
.macro removeaction <name> <index>Delete step index (0-based).
.macro delete <name>Delete the macro.
.macro new dupe1
.macro add dupe1 DELAY ticks=5
.macro show dupe1
.macro dupe1 10 20        # run 10 times, 1 second apart
.macro stop
When you are piloting a Multi bot (POV mode), .macro runs, loops and stops on that bot instead of your own player.

3.5 Packets

DIH sits on every outgoing packet. These commands drive the same controls as the on-screen Send / Delay / Flush / Clear buttons and the packet gate manager.

.packet … — alias .pkt

FormEffect
.packet statusShow whether sending and delaying are on, and how many packets are queued.
.packet send [on|off|toggle]Toggle sending of GUI/outgoing packets. Off = packets are not sent.
.packet delay [on|off|toggle]Toggle the delay queue. Turning delay off flushes what was held.
.packet flushRelease every queued packet to the server now.
.packet clearThrow away every queued packet.

.delay [on|off|toggle]

Shortcut for .packet delay.

.gate … — alias .packetgate

A gate is a rule that cancels, holds, or whitelists specific packet types until you end it. Packet names are class names (tab-complete), separated by spaces or commas.

FormEffect
.gate cancel <packet…>Drop matching packets.
.gate delay <packet…>Hold matching packets in the queue.
.gate allow <packet…>Drop everything except these.
.gate end [id]End a gate and flush what it held. The default id for gates made here is cli.
.gate clearEnd every gate.
.gate statusList active gates.
.gate cancel ServerboundContainerClosePacket
.gate status
.gate end

.send <PacketClass> [field=value …]

Builds and sends any client-to-server packet by class name. Press Tab after the space to search packet classes and, after the packet name, its fields. Sending bypasses the delay queue. Server-to-client packets are refused. If the arguments are incomplete the client prints the fields the packet needs. Add dry (also dryrun, preview, nosend) to build the packet without sending it. Values can be quoted (message="hello") and raw bytes given as hex:….

.send ServerboundSetCarriedItemPacket slot=0
.send ServerboundChatPacket message="hello" dry

3.6 Container GUIs

.gui … — alias .screen

The building blocks of the desync workflow (same code as the on-screen buttons).

FormEffect
.gui saveStore the current container screen locally (no packet).
.gui desyncSend the close-container packet to the server but keep the screen open on your side.
.gui loadRe-open the stored screen (same as the V key).
.gui close / .gui close packetClose the screen and tell the server.
.gui close nopacketClose the screen locally only.

.click-slot <slot> [click] [times]

Clicks a slot in the open GUI or your inventory.

Slot names: gui1, gui2… (container slots), hotbar1–hotbar9, inventory1–inventory27, helmet, chestplate, leggings, boots, offhand, or a raw visible numeric id.

Click modes (default left; times up to 100 000):

ModeWhat it does
left / right / middleNormal pick-up clicks.
shift-left / shift-rightQuick-move.
cloneMiddle-click clone (creative).
pickup-allDouble-click collect.
drop-itemDrop times items from the slot.
drop-stackDrop the whole stack (no repeat count).
swap <1-9> [times]Swap with that hotbar slot.
.click-slot gui5
.click-slot gui5 shift-left
.click-slot hotbar1 swap 3
.click-slot inventory4 drop-item 16

.click-item "<item name>" [click] [times]

Same as .click-slot, but finds the slot by the item's visible name in the current GUI (case/format-insensitive). Quote names with spaces.

.click-item "Confirm"
.click-item "Diamond Sword" shift-left

.xcarry <slot>

Stashes the item in your hand into a slot the server doesn't expect to hold items, so you keep it. Open your inventory (E) first. Slots: craft1–craft4, craft5 (also crafting5/result, the crafting output), helmet, chestplate, leggings, boots, offhand, or cursor (keep holding it on the cursor).

.xcarry craft1
.xcarry cursor

.tp …

Ground-first teleport made of paced HClip bursts.

FormEffect

.tp base

.copypos

Copies your block position (x y z) to the clipboard. Uses your vehicle's position while riding and the camera position while in freecam.

3.9 Player & world

.gamemode <survival|creative|adventure|spectator>

Changes your real game mode without sending a chat command (needs permission on the server).

.fakegm <survival|creative|adventure|spectator|reset>

Client-side-only fake game mode. reset (or r) returns to the real one.

.damage <amount>

Sends /damage @s <amount> (0.1–1024). Only works where you're allowed to use /damage (op).

.rv [player|stop]

Remote view: watch another loaded player's point of view.

  • .rv — watch the player you're looking at.
  • .rv <name> — watch a named loaded player.
  • .rv stop — return to your own view.

.namescrape [count] | deep [count] | pause | resume | stop — alias .scrapenames

Collects player names from the server and copies them to the clipboard. count limits how many, deep does an exhaustive scrape; pause/resume/stop control a running scrape.

3.10 Server, chat & network

.server [info|plugins|tps]

  • .server / .server info — open the server info panel.
  • .server plugins — open the plugin scanner tab.
  • .server tps — print the estimated server TPS.

.plugins

Shortcut for .server plugins.

.say <message>

Sends a chat message. If it starts with / it's sent as a server command. Useful in binds and macros, and for sending text that begins with your DIH prefix.

.clear — alias .cls

Clears the chat window.

.disconnect

Disconnects from the server.

3.11 Multi, LAN Sync & Matchmaking

.multi …

Multi runs several accounts (bots) at once.

FormEffect
.multi / .multi openOpen the Multi menu (or the console if a batch is running).
.multi launch <profile>Start a saved Multi profile.
.multi statusBatch name, ready and connected counts.
.multi stopDisconnect every bot in the batch.

POV mode. While you're piloting a bot, these commands run on the bot instead of you: click-slot, click-item, change-slot, drop, send, say, damage, hclip, vclip, tp (disconnect disconnects the bot). Requires an active LAN Sync session.

  • .sync send <message or /command> — send the same chat line from every synced client.

.matchmaking — alias .mm

Toggles the Matchmaking overlay.

.irc <message>

Sends a message to your Matchmaking lobby's chat (join or create a lobby first).

#nether — aliases #nc, #coords

Converts coordinates between Overworld and Nether (X/Z ÷8 or ×8, Y unchanged).

#portal — aliases #whereportal, #findportal

Walk to (and by default into) the nearest cached nether portal; explores if none is known. #portal skip blacklists the nearest one and goes to the next. Turn off auto-entry with #set enterPortal false.

#sleep / #autosleep

  • #sleep — go to the nearest cached bed and sleep when it's night (or thundering); waits there if it's day.
  • #autosleep [on|off|interrupt|status] (alias #nightowl) — do that automatically every night. interrupt toggles whether it may interrupt other tasks (default: only when idle).

4.4 Search, cache & memory

These read Baritone's chunk cache — no extra packets.

#search <block> [goto] — alias #blocks

Lists the nearest matches (loaded chunks + cache) with distance and direction. #search <block> goto paths to the nearest; #search <N> goto paths to result N.

The built-in help also lists #s as an alias, but #s actually opens #sel. Use #search or #blocks.

#find <block…>

Looks up cached positions of blocks (tab-complete only offers cached blocks).

#chest — aliases #chests, #findchest

DIH records the contents of every container you open. Search it:

#chest <item>          containers holding <item> (partial, case-insensitive)
#chest <item> goto     search and path to the best result
#chest <N> goto        path to result N of the last search
#chest list [page]     browse everything recorded
#chest stats
#chest forget <N>
#chest clear

Saved in baritone/chest_memory.json.

#bases — alias #basefinder

Clusters cached "base indicator" blocks (beacons, ender chests, enchanting tables, anvils, shulkers…) into likely player bases.

#bases            top 10 in this dimension
#bases <N>
#bases pie        breakdown by indicator type
#bases <N> goto   path to base N

Tune with baseFinderMinScore (30), baseFinderMinIndicators (3), baseFinderEpsilon (50). Run #repack first to include freshly loaded chunks.

#heatmap — alias #activity

Scores 512×512 zones by player activity (adds portals, hoppers, observers, heads, jukeboxes). #heatmap [N], #heatmap <N> goto. Also drawn as a JourneyMap layer.

#players — aliases #player, #seen

Player-sighting log (always recorded, even with #threats off).

#players              everyone seen
#players <name>       sighting history
#players goto <name>  path to their last known position
#players forget <name>
#players clear
#players stats

#menu — alias #gui

Reads and clicks server plugin GUIs (shops, warp menus, RTP).

#menu dump                     print every non-empty slot of the open menu
#menu click <matcher>          click a slot in the open menu
#menu run <command> <matcher>  run /command, wait for the menu, click
#menu stop                     cancel a pending click

Matchers: item:<id> (most reliable), slot:<n> (0-based), or text from the name/lore.

#menu run warps item:compass
#menu click slot:18

4.5 Seeds & structures

#seedinput — alias #seed

Stores the world seed for the current server (needed for #seedmap, #structure, #where on multiplayer; shared with OreSim). Singleplayer needs nothing.

#seedinput <seed>         number or text (text is converted like world creation)
#seedinput <seed> force   keep it even if it fails verification
#seedinput / check        show the seed and whether it matches the server's hash
#seedinput clear

#structure <name> — aliases #struct, #locate

Finds the nearest structure and paths there. Names: village, stronghold, fortress (nether_fortress), bastion, mansion, monument, ancient_city, end_city, mineshaft, buried_treasure, desert_pyramid, jungle_pyramid, pillager_outpost, shipwreck, igloo, swamp_hut, ocean_ruin, ruined_portal, trial_chambers, trail_ruins.

#where [structure]

#where prints your X Y Z and dimension. #where <structure> gives the nearest structure's coordinates, distance and direction without moving.

#seedmap — aliases #structures, #smap

Draws every biome-validated structure on the JourneyMap fullscreen map (chat list without JourneyMap).

#seedmap                     everything within 2000 blocks
#seedmap <radius>            up to 8000
#seedmap <kinds…>            e.g. #seedmap village monument
#seedmap <r> at <x> <z>      centre elsewhere
#seedmap wp                  also add landmark waypoints
#seedmap strongholds         nearest strongholds (+ all 128)
#seedmap off                 hide the overlay

4.6 Safety & automation

#threats — alias #threat

Chat alert when a player enters range. #threats toggles; on, off, <N> (radius, default 64), status.

#flee

Disconnects you (or runs a command) when a trigger fires. All triggers start off; by default they're only checked while Baritone is busy.

#flee                     status
#flee on | off            master switch
#flee players [on|off|N]  players within N blocks
#flee health <hearts>
#flee hunger <food>
#flee tool <durability>
#flee pickaxe             none left while mining
#flee full                inventory full
#flee action disconnect|command|stop
#flee command /spawn      command to run with action=command
#flee check always        also check while idle (default: busy)
#flee reconnect on        let AutoReconnect reconnect afterwards
#flee gui                 settings screen
#flee test                fire the action now

#listentomine — alias #ltm

Watches chat for a word (default legendary), then runs a warp (default /warp mine), waits, frees a slot if the inventory is full, and #mines the target (default ancient_debris). #ltm toggles; on, off, status. Configure with #set listenToMineWord, listenToMineWarp, listenToMineTarget, listenToMineWarpDelay (40), listenToMineCooldown (200).

5. Name clashes between . and #

The two systems are separate, so similar names do different things:

You typeDoes
.wpDIH waypoints (per server, used by .tp).
#wpBaritone waypoints (tagged, used by #wp goto).
.setDIH module setting.
#setBaritone setting.
.guiSave / desync / load container screens.
#gui#menu — read and click plugin GUIs.
.helpDIH command help.
#helpBaritone command help.

Inside the # system, later registrations win:

  • #flee is the Flee trigger system; the run-away command is #runaway / #escape.
  • #s is #sel; for search use #search / #blocks.
