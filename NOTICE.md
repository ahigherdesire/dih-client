## Modifications

DIH Client is a modified version of Autism Client (upstream release of 2026-09-07). Changes made by
ahigherdesire between 2026-09-07 and 2026-09-24 include:

- Renamed the project, mod id, packages, assets and branding to DIH Client (via an intermediate
  "XINYUAN Client" name); redrew the logos and icon.
- Integrated a Baritone / MinecraftAI pathfinding and AI feature set.
- Added `#seedmap`, `#seedinput`, `#structure` and `#where` with structure validation run through
  vanilla world generation, and a JourneyMap plugin (seed map, heatmap, waypoints).
- Restored Baritone path, goal and ESP rendering on Minecraft 26.2.
- New UI styling and the Geist UI font; removed donation screens and countdown locks.
- Added migration of settings from the previous names, a macro authoring CLI, and assorted fixes.

The full history is in the git log.
