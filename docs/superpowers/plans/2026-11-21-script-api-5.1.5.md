# Script API 5.1.5 Implementation Plan

> **For agentic workers:** Use test-driven development and independent parallel tasks, then integrate and review the complete change.

**Goal:** Implement all proposed script APIs and publish DIH Client 5.1.5.
**Architecture:** Extend the existing interpreter; optional Meteor bridge, serial cooperative callbacks, independent supervisor scripts, server-synchronised inventory operations, atomic scoped storage with token-owned leases.
**Tech Stack:** Java, Minecraft/Fabric, Gson, Java HTTP client, Gradle/Stonecutter, JUnit.
**Spec:** 2026-11-21-script-api-spec.txt (user supplied; approach approved in chat).

## Global Constraints
- Preserve existing working-tree changes. Never stage unrelated work.
- Inventory slots 1–36 and "offhand"; no optimistic success claims.
- Never run one interpreter concurrently or block the Minecraft client thread.
- No automatic mining on join; explicitly armed reconnect only; death disarms.
- Secrets local only. Meteor optional. Death Replay remains external.
- Release retains the 5.1.4 matrix: Fabric 1.21.11/26.1.2 plus Fabric/NeoForge/Forge 26.2/26.3.

## Review Focus
- Cursor interruption and full inventory swaps preserve items.
- Expired lock owners cannot renew or remove a replacement lease.
- Concurrent shared-file edits cause a conflict rather than lost updates.
- Monitoring runs during waits and HTTP; callbacks cannot recurse indefinitely.
- Disconnection and death preserve snapshots and never implicitly resume mining.

## Tasks
- [x] Storage: scoped files, conflict detection, renewable process-safe leases, HTTP/secrets and tests.
- [x] Inventory: offhand reads, exact transfer/drop, cursor inspection, GUI actions/lore/name matching and tests.
- [x] Game: environment/threat/target information, aiming/actions/keys/eating, Meteor optional adapter and tests.
- [x] Runtime: JSON object access, event dispatch while waiting, supervision lifecycle, local commands, reconnect/respawn/focus and tests.
- [x] Integration: document APIs and examples; run tests, compile all eight release targets, review fixes.
- [ ] Release: version 5.1.5, release notes, build artifacts, scoped commit and publish; verify published assets.

## Validation
Each owner writes failing behavioral tests first, verifies failure, implements, verifies pass. Root serializes Gradle runs to avoid Stonecutter races. Baseline :26.2-fabric:test passed before changes (2026-11-21).

The original checkout was behind the published release; implementation was transferred into a managed worktree based on origin/beta (5.1.4), retaining unrelated original edits. Final full 26.2/26.3 tests reported 4,300 tests, zero failures/errors, two skips. All eight targets compiled. The complete API catalogue checked against the actual runner on both primary versions. Independent review found no remaining P1/P2 issues after adding late-session fencing and safe JSON fallback. Publication is tracked by the GitHub Release workflow for version 5.1.5.
