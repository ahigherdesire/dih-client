    Commands

    Every chat command in DIH Client and how to type it. Client commands start with . and never reach the server. Pathfinder and AI commands start with #.

    116 commands · Minecraft 26.2 · press / to search

    Basics

    Two prefixes

    DIH has two command systems, both typed in normal chat.

    PrefixWhat it runsList them with
    .DIH client commands. They never reach the server..commands or .help
    #The built-in Baritone pathfinder and the AI.#help

    The . prefix is % instead when Meteor Client is also installed, because Meteor already uses .. Change it with .prefix; the choices are . % - _ * # @ & =. The # prefix is the Baritone prefix setting.

    Getting help in game

    Type a command with no arguments to see its usage. .help <command> shows a client command's description and aliases, and #help <command> prints the full help of a # command. Tab completion works on every argument: modules, macros, item and block ids, packet classes, slot names, players and waypoints.

    Turning DIH off

    ^toggledih, typed in chat exactly like that, turns the whole client on or off. While panic hide has locked the client, every DIH command is swallowed under any prefix, so nothing reaches the server.

    Notation

    WrittenMeans
    <arg>Required.
    [arg]Optional.
    a|bPick one.
    …Any number of words.
    on|off|toggleAlso accepts enable/true/1 and disable/false/0. Leaving it out toggles.

    Examples use the default . prefix. Swap in yours if you changed it.

    Lite builds and addons

    Lite builds leave out setting, irc, matchmaking, multi, toggle, modules, oresim, ghostblock, friend, waypoints, gamemode, fakegm, xcarry, rv and namescrape, and in the beta also schem, invsee, tools and ai. Addons can add their own . commands; one whose name is already taken shows up as <addon>:<name>.

    Beta commands

    Commands marked Beta are in the 5.1 beta builds and not in 5.0.1 stable. The beta download is on the website and on GitHub releases. Everything else works in both.

    Same name, different command

    The two systems are separate, so these pairs do different things.

    ClientPathfinder
    .wp saves DIH waypoints, which .tp can use.#wp manages Baritone's tagged waypoints.
    .set changes a module setting.#set changes a Baritone setting.
    .gui saves, desyncs and reloads container screens.#gui is #menu, which reads and clicks plugin GUIs.
    .help lists client commands.#help lists pathfinder commands.
    .ai (beta) gives the AI an objective it works through with its tools.#ai sets up the chat AI that plays through Baritone commands.

    Two # aliases also point somewhere other than their help text says. #flee opens the Flee trigger system, so use #runaway or #escape to run away. #s opens #sel, so use #search or #blocks to search.

    .Client commands

    Help & info

    .help

    Show every client command, or the description and aliases of one.

    .help
.help macro

    .commands

    Also .cmds

    List every command name on a few lines, with the current prefix.

    .modules

    Also .features

    List every installed module, built-in and addon.

    .oresim

    Explain why OreSim (the Xray module's ore predictor) is or isn't drawing ores.

    It reports whether Xray is on, its mode and style, the seed in use or why it's missing, where that seed is saved, how many ore families are selected, the local worldgen status, chunks simulated, and how many nearby real ores matched a prediction.

    Modules & settings

    .toggle

    Also .t

    Turn a module on, off, or flip it.

    .toggle <module> [on|off|toggle]
    .toggle killaura
.t scaffold on

    .setting

    Also .set

    Read or change any module setting without opening the module menu.

    UsageEffect
    .setting <module>List every setting with its value.
    .setting <module> <key>Show one setting.
    .setting <module> <key> <value…>Set it. reset or default restores the default.

    Write module names that contain spaces with -, such as storage-esp.

    .set killaura range 4.2
.set killaura range reset

    .friend

    Also .team

    Manage your friends list. Combat modules leave friends alone, and ESP and nametags can mark them.

    UsageEffect
    .friendShow the list.
    .friend add <name>Add a player. Tab completes players on the server.
    .friend remove <name>Remove a player.
    .friend clearEmpty the list.

    .ghostblock

    Also .gb

    Place blocks that only you can see.

    UsageEffect
    .gb toggleTurn the GhostBlock module on or off.
    .gb resetRemove every ghost block and show the real blocks again.
    .gb creative [on|off|toggle]Fake creative mode: everything you place becomes a ghost block. Also turns the module on.
    .gb blockShow the armed block.
    .gb block <id>Arm a block to place, such as diamond_block. Also turns the module on.
    .gb block offDisarm it (none and reset work too), so held blocks place ghosts again.

    Keybinds & prefix

    .bind

    Bind a key to any chat line: a client command, a # command or plain chat.

    .bind <key> <command…>
.bind clear <key>
    .bind G .macro myMacro
.bind H #goto 0 0
.bind clear G

    Right Shift (module menu) and V (reload the stored GUI) are set in the config, not with .bind. The packet queue keys (flush, clear, toggle send, toggle delay, toggle logger) start unbound.

    .binds

    List every command keybind.

    .prefix

    Show, change or reset the client command prefix.

    .prefix
.prefix -
.prefix reset

    The choices are . % - _ * # @ & =. reset goes back to ., or % with Meteor installed. Picking . while Meteor is installed keeps % and warns you.

    Macros

    .macro

    Run macros, loop them, or build them from chat. Macros are saved in config/dih/dih_macros.nbt.

    Run
    UsageEffect
    .macro <name>Run once.
    .macro <name> <times>Run up to 100 000 times, each run starting when the last one ends.
    .macro <name> <times> <delayTicks>Same, waiting delayTicks between runs (20 ticks is 1 second, up to 72 000).
    .macro stopStop every macro and loop.
    .macro stop <name>Stop one macro and its loop.
    .macro clearCancel queued loops and let the current run finish.
    Build from chat
    UsageEffect
    .macro new <name>Create an empty macro.
    .macro add <name> <TYPE> [field=value …]Add a step. TYPE tab completes. Values can't contain spaces.
    .macro show <name>List the steps with their numbers.
    .macro removeaction <name> <index>Delete step index, counting from 0.
    .macro delete <name>Delete the macro.
    .macro new dupe1
.macro add dupe1 DELAY ticks=5
.macro dupe1 10 20
.macro stop

    While you pilot a Multi bot, .macro runs, loops and stops on that bot instead of you.

    Schematics

    .schem

    Beta 5.1 beta only, not in 5.0.1 stable.

    Also .schematic .schematics

    Load schematic files, place them in the world, see what is still to build, and let Baritone build them. Works like a built-in Litematica.

    It reads .litematic, .schematic (MCEdit, Schematica and WorldEdit), .schem (Sponge v1 to v3) and vanilla .nbt files. Files live in .minecraft/schematics. You don't need the Litematica mod; if you have it, its placements stay separate and #litematica still builds those.

    Get a file in
    UsageEffect
    .schem menuOpen the Schematics screen: your files on the left, this world's placements on the right. The module's Menu Key does the same.
    .schem openPick a file from anywhere with your system's file picker, starting in Downloads. The module's Open File Key does the same.
    .schem import <path>The same with a typed path, quotes and backslashes allowed, or a file name in Downloads.
    .schem listList the files in the schematics folder.
    .schem place <file> [x y z]Place a file from the folder in front of you, or at a position. .schem load is the same.

    You can also drag files onto the game window. One file is placed straight away; several open the Schematics screen. The screen also lists your 20 newest schematic downloads, tagged "Downloads". Picked and dropped files are copied into the schematics folder, and nothing there is overwritten: a different file with the same name becomes name (2).litematic.

    Place it

    A new placement goes four blocks in front of you and you are straight back in the game with the camera free. Until you keep it, these keys move it, and a panel at the top of the screen lists them:

    KeyDoes
    Arrow keysMove it forward, back, left or right, relative to where you face. Hold to repeat.
    Page Up / Page DownMove it up or down.
    RTurn it 90° clockwise.
    MMirror it (none, then x, then z).
    GDrop it onto the ground at its column.
    EnterKeep it where it is.
    BackspaceRemove it.

    The keys only do this while a new placement is being placed and no screen is open, so they never clash with the game otherwise. If another mod also uses R, M or G, it may react too while you place.

    Move it later
    UsageEffect
    .schem adjustOpen the mouse placement screen: right-click or drag puts it where you point, the wheel turns it, Shift + wheel pushes it nearer or farther, middle-drag looks around, left-click keeps it and Esc puts it back. The Move button and the Adjust Key open it too.
    .schem move <x y z>Put its corner at those coordinates.
    .schem herePut its corner where you stand.
    .schem nudge <dx dy dz>Shift it by that many blocks.
    .schem rotate [quarters]Turn it 90° clockwise, or by -3 to 3 quarter turns. The Rotate Key does one turn.
    .schem mirror [none|x|z]Cycle the mirror, or set it. The Mirror Key cycles it.

    These act on the selected placement: the last one you placed or picked.

    Remove it or hide it
    UsageEffect
    .schem removeRemove the selected placement from the world.
    .schem remove <n>Remove placement n, by its number in .schem placements or the start of its name.
    .schem remove allRemove every placement in this world.
    .schem hide [n]Stop drawing it but keep it, with its position and turn. .schem show [n] brings it back.
    Schematics screenClick the placement on the right, then Remove or Show / Hide.
    BackspaceRemoves a placement you haven't kept yet.

    Removing only takes the placement out of the world; the file stays in the schematics folder. To hide every placement at once without losing them, turn the Schematics module off, for example with .toggle schematics.

    See what it needs
    UsageEffect
    .schem materials [n]The first items still needed, in chat, against your inventory.
    MaterialsIn the Schematics screen: the whole list as a table with Total, Have and Missing, biggest shortfall first. It updates every 2 seconds, scrolls, and Missing only hides what you have enough of.
    .schem materials csv [n]Save the list to .minecraft/schematics/materials/<name>-materials.csv for a spreadsheet, with item, name, needed, have and missing. Save CSV in the screen does the same. Saving again replaces the file.
    .schem verify [n]Count the blocks that are right, missing, the wrong block, the wrong state or extra, in loaded chunks.

    In the world, the overlay tints blocks that aren't right: blue missing, red the wrong block, orange the right block turned wrong, pink an extra block. Blocks in shulker boxes or chests don't count as yours.

    Build it
    UsageEffect
    .schem build [n]Hand the placement to Baritone's builder, the one #build uses. Build in the screen does the same.

    It turns on #allowInventory so blocks anywhere in your inventory get used, and it pauses when a block runs out, then lists what is still to place. Get those and type #resume. If it stops on stairs or other turned blocks, #buildIgnoreDirection true lets it place them. To build with no blocks at all, see #construct.

    Placements and layers
    UsageEffect
    .schem placementsList this world's placements with their numbers.
    .schem select <n>Make placement n the selected one.
    .schem info [n]Its file, position, turn, size and block count.
    .schem reload [n]Read its file again after you changed it.
    .schem layer <all|single|below|above> [y]Draw every layer, one, or those below or above a height (your feet by default).

    Placements are saved per server, or per world folder in singleplayer, and come back when you rejoin. The list shows placements from every dimension, marked "(Nether)" and so on when they're not in yours.

    Packets

    .packet

    Also .pkt

    Control the outgoing packet queue, the same as the Send, Delay, Flush and Clear buttons.

    UsageEffect
    .packet statusShow whether send and delay are on, and how many packets are queued.
    .packet send [on|off|toggle]With send off, GUI packets aren't sent.
    .packet delay [on|off|toggle]Hold packets in the queue. Turning delay off sends what was held.
    .packet flushSend every queued packet now.
    .packet clearThrow every queued packet away.

    .delay

    Shortcut for .packet delay.

    .delay [on|off|toggle]

    .gate

    Also .packetgate

    Cancel, hold or whitelist specific packet types until you end the gate.

    UsageEffect
    .gate cancel <packet…>Drop matching packets.
    .gate delay <packet…>Hold matching packets in the queue.
    .gate allow <packet…>Drop every packet except these.
    .gate end [id]End a gate and send what it held. Gates made here use the id cli.
    .gate clearEnd every gate.
    .gate statusList active gates.

    Name packets by class (they tab complete), separated by spaces or commas.

    .gate cancel ServerboundContainerClosePacket
.gate end

    .send

    Build and send any client-to-server packet by class name.

    .send <PacketClass> [field=value …]

    Press Tab after the space to search packet classes, and again after the name for its fields. If you leave fields out, DIH lists the ones the packet needs. Quote values with spaces (message="hello") and give raw bytes as hex:…. Add dry (or dryrun, preview, nosend) to build the packet without sending it. Sent packets skip the delay queue, and server-to-client packets are refused.

    .send ServerboundSetCarriedItemPacket slot=0
.send ServerboundChatPacket message="hello" dry

    Container GUIs

    .gui

    Also .screen

    Save, desync and reload container screens, the same as the on-screen buttons.

    UsageEffect
    .gui saveStore the open screen on your side. Sends nothing.
    .gui desyncTell the server the screen closed but keep it open for you.
    .gui loadReopen the stored screen, like the V key.
    .gui closeClose the screen and tell the server. .gui close packet does the same.
    .gui close nopacketClose the screen on your side only.

    .click-slot

    Click a slot in the open GUI or your inventory.

    .click-slot <slot> [click] [times]

    Slots: gui1, gui2… for container slots, hotbar1–hotbar9, inventory1–inventory27, helmet, chestplate, leggings, boots, offhand, or a raw slot number.

    ClickDoes
    left, right, middleNormal clicks. left is the default.
    shift-left, shift-rightQuick move.
    cloneMiddle-click clone (creative).
    pickup-allDouble-click collect.
    drop-itemDrop times items from the slot.
    drop-stackDrop the whole stack. Takes no count.
    swap <1-9> [times]Swap with that hotbar slot.

    times goes up to 100 000.

    .click-slot gui5 shift-left
.click-slot hotbar1 swap 3
.click-slot inventory4 drop-item 16

    .click-item

    Click an item in the open GUI by its visible name. Takes the same clicks as .click-slot.

    .click-item "<item name>" [click] [times]

    Matching ignores case and colour codes. Quote names that contain spaces.

    .click-item "Confirm"
.click-item "Diamond Sword" shift-left

    .xcarry

    Stash the item in your hand in a slot the server doesn't expect to hold items, so you keep it.

    .xcarry <slot>

    Open your inventory with E first. Slots: craft1–craft4, craft5 (the crafting output, also result), helmet, chestplate, leggings, boots, offhand, or cursor to keep holding it on the cursor.

    Inventory & items

    .drop

    Drop your held stack, your whole inventory, or a set amount of an item.

    UsageEffect
    .drop handDrop the held stack.
    .drop fullinventoryDrop every stack in the inventory and hotbar.
    .drop <amount>Drop amount of the held item, taking from other stacks of it if needed.
    .drop <amount> <item>Drop amount of that item from anywhere in the inventory.
    .drop 32
.drop 10 diamond

    .change-slot

    Select a hotbar slot.

    .change-slot <1-9>

    .give

    Put an item in your selected hotbar slot. Needs creative mode.

    .give <item> [count]

    count is 1 to 64.

    .give tnt 64

    .nbt

    Inspect or copy the item in your hand.

    UsageEffect
    .nbtOpen the component (NBT) inspector for the item in your main hand, or offhand if it's empty. .nbt get does the same.
    .nbt copyCopy a /give command that recreates the item.

    Movement & position

    .vclip

    Clip up or down through blocks with movement packets.

    UsageEffect
    .vclip <blocks>Move up (positive) or down (negative).
    .vclip topFind a safe spot above you and clip there.
    .vclip bottomFind a safe spot below you and clip there.
    .vclip paper <blocks>Same as <blocks>, padded for Paper servers. default is the same.
    .vclip single <blocks>Use one movement packet. normal is the same.
    .vclip custom <blocks> <segment> [maxPackets] [updateLocal] [vehicle] [forceGround]Set every option: segment 1–50 blocks per step, maxPackets 1–100, then true or false for each flag.
    .vclip 5
.vclip -30
.vclip custom -25 10 20 true true

    .hclip

    Clip forward through blocks with movement packets.

    UsageEffect
    .hclip <blocks>Clip forward blocks.
    .hclip forwardClip through the wall in front of you to the free space past it.
    .hclip backSame, through the wall behind you.
    .hclip paper <blocks>Padded for Paper servers. default and padding are the same.
    .hclip single <blocks>Use one movement packet. normal is the same.
    .hclip custom <blocks> <segment> [maxPackets] [updateLocal] [vehicle] [forceGround]Set every option, like .vclip custom.

    .tp

    Teleport in paced HClip bursts, ground first.

    UsageEffect
    .tp <x> <y> <z> [maxPackets] [pauseMs]Teleport. ~ offsets work. maxPackets 1–100 per burst, pauseMs 50–10 000 between bursts.
    .tp <waypoint>Teleport to a saved DIH waypoint. Quote names with spaces.
    .tp statusShow the running teleport.
    .tp stopCancel it.
    .tp config <maxPackets> <pauseMs>Save new defaults.
    .tp resetGo back to 20 packets and 500 ms.

    It works while riding but won't start while a macro runs.

    .tp ~100 ~ ~
.tp 1200 64 -300 30 400
.tp base

    .copypos

    Copy your block position as x y z. Uses your vehicle while riding and the camera in freecam.

    .waypoints

    Also .wp

    Save and manage DIH waypoints for this server or world. They're separate from Baritone's #wp.

    UsageEffect
    .wpSave a waypoint here, named Waypoint 1, Waypoint 2…
    .wp <x> <y> <z>Save one at those coordinates.
    .wp guiOpen the waypoint manager. .wp list does the same.
    .wp del <name>Delete a waypoint.
    .wp clearDelete every waypoint for this server or world.

    .dismount

    Get off any vehicle.

    .enchant

    Beta 5.1 beta only, not in 5.0.1 stable.

    Enchant the item in your hand with any enchantment, at any level up to 255. Needs creative mode.

    UsageEffect
    .enchant <enchantment> [level]Add one, at its normal maximum level unless you give one. Tab completes the names.
    .enchant all [level]Add every enchantment.
    .enchant remove <enchantment>Take one off.
    .enchant clearTake them all off.
    .enchant plan <enchantments>Works in survival: from the villager trades you've opened in this world, find who sells those books and plan the trip.

.enchant all
.enchant plan mending unbreaking

    .invsee

    Beta 5.1 beta only, not in 5.0.1 stable.

    Look at a loaded player's armour and held items, with durability and enchantments. View only.

    .invsee
.invsee <player>

    With no name it opens for the player you're looking at.

    Multi, LAN Sync & Matchmaking

    .multi

    Run several accounts at once.

    UsageEffect
    .multiOpen the Multi menu, or the console while a batch runs. .multi open does the same.
    .multi launch <profile>Start a saved profile.
    .multi statusShow the batch name and how many bots are ready and connected.
    .multi stopDisconnect every bot.
    .multi macro <macro> [bot]Run a macro on one bot, or all of them.

    While you pilot a bot, click-slot, click-item, change-slot, drop, send, say, damage, hclip, vclip and tp run on the bot, and disconnect disconnects the bot. delay, gamemode, server, plugins, matchmaking and dismount are blocked so they can't touch your main account.

    .sync

    UsageEffect

    .sync macro <name>Start a macro on every synced client at the same moment.

    .matchmaking

    Also .mm

    .irc <message>

    Addons & AI tools

    .addons

    Beta 5.1 beta only, not in 5.0.1 stable.

    Also .addon

    Open the addon store: browse, install and manage addons. My Addons lists what is installed.

    Install from a card, click Install again to confirm, and restart Minecraft. DIH checks each download's SHA-256 before installing it. The store is also on the website's Addons page.

    .ai

    Beta 5.1 beta only, not in 5.0.1 stable.

    Give the AI an objective in plain words and let it work through it with its tools.

    UsageEffect
    .ai start <objective>Start a run, for example .ai start get full iron armor. The progress panel opens.
    .ai statusWhat it's doing.
    .ai whyWhy it made its last choice.
    .ai pausePause the run. .ai resume carries on.
    .ai stopStop the run.
    .ai confirmAllow a step it asked permission for.
    .ai setupPick the model and key.
    .ai panelShow or hide the progress panel.

    This is a different thing from #ai, the chat AI that plays through Baritone commands.

    .tools

    Beta 5.1 beta only, not in 5.0.1 stable.

    Also .tool

    Run one of the AI's tools yourself, without the AI.

    UsageEffect
    .toolsList every tool by category.
    .tools help <tool>Its arguments and what it does.
    .tools <tool> [args]Run it. Tab completes tools and arguments. Tools that could cost you something ask you to click [confirm] first.

    .update downloadOpen the new jar's download. Replace the old jar in mods and restart.
    .update onTurn automatic checks on.
    .update offTurn them off. DIH then never contacts GitHub.

    #construct

    Beta 5.1 beta only, not in 5.0.1 stable.

    Also #buildfromscratch

    Build a schematic starting with none of its blocks. It works out what the blocks cost, gathers a batch that fits your inventory with #acquire, builds what it can, and repeats until it's done.

    UsageEffect
    #construct <file> [x y z]Build a file from the schematics folder here, or at x y z.
    #construct plan <file> [x y z]List what it takes and what you still need to gather.
    #construct statusWhat it's doing.
    #construct stopStop. #stop and #cancel work too.

    It never mines inside the build, keeps the blocks it gathered, and skips blocks no item places, like water. It turns allowInventory on while it runs and back off after.

    Survival on autopilot

    #acquire

    Beta 5.1 beta only, not in 5.0.1 stable.

    Also #aquire

    Get an item from whatever you have now: it plans the whole chain (trees, planks, tools, ore, a furnace, mobs) and runs it.

    UsageEffect
    #acquire <item> [count]Get it, such as #acquire stone_pickaxe or #acquire torch 64.
    #acquire <count> <item>The same, count first.
    #acquire food [count]The cheapest food that covers 10 to 20 food points, or count of it.
    #acquire plan <item> [count]Print the steps without doing anything.
    #acquire statusThe current step and progress.
    #acquire stopStop. #stop works too, and #pause pauses it.

    Items can be typed loosely: iron pick, Iron Pickaxe and iron_pickaxe all work. It counts what you already carry, uses a crafting table or furnace nearby or places its own, eats when you're hurt or hungry, and re-plans from your real inventory when a step falls short or a tool breaks. It never runs server commands or teleports. Tune it with the acquire settings in #set, such as acquireDropJunk to let it throw junk away when full.

    #eat

    Beta 5.1 beta only, not in 5.0.1 stable.

    Eat one item now. It never eats on its own.

    UsageEffect
    #eatEat the food that fills your missing hunger with the least waste.
    #eat <item>Eat that item, such as #eat golden_apple.
    #eat stopStop eating.

    Harmful food is only eaten when you're starving and have nothing else, and golden apples only at low health. Pathing pauses while you eat.

    #beat

    Beta 5.1 beta only, not in 5.0.1 stable.

    Play towards beating the game in 9 phases: gear, a nether portal, blaze rods, pearls, home, eyes of ender, the stronghold, the End and the dragon. Progress is saved per world.

    UsageEffect
    #beatStart, or carry on with this world's saved run.
    #beat planPrint every phase and step first.
    #beat resumeContinue the saved run.
    #beat statusThe phase and its progress.
    #beat stopStop. The run stays saved.
    #beat restartForget the saved run and start over.

    Phases that aren't finished yet, like going through portals, finding structures and the dragon fight, stop the run with a message saying so.

    #parkour

    Beta 5.1 beta only, not in 5.0.1 stable.

    Run parkour with each jump solved exactly, using only normal key presses and turning.

    UsageEffect
    #parkourFollow the course you're standing on until no jumps are left ahead.
    #parkour goto <x> <y> <z>Jump your way to that block.
    #parkour solve <x> <y> <z>Work out one jump onto that block and say how, without moving.
    #parkour statusWhat it's doing.
    #parkour stopStop. #stop and #cancel work too.

    It handles neos, strafes, head-hitters, ladders and momentum jumps.

    AI

    #ai

    Let a language model read server chat and play by running # commands. Messages from trusted players are orders; everyone else's are only context.

    Set up
    #ai key <api-key>
#ai url <base-url>
#ai model <name>
#ai trust <player>
#ai on

    The key can also come from the MINECRAFTAI_LLM_KEY environment variable. Any OpenAI-compatible endpoint works, and the default model is qwen-plus.

    Use
    UsageEffect
    #ai <anything>Tell it to do something yourself.
    #ai statusShow the setup, token use and last error.
    #ai offStop listening.
    #ai auto [on|off]Let it think on a timer.
    #ai chat [on|off]Let it talk in server chat.
    #ai trigger <word|none>Make trusted players start orders with a wake word.
    #ai goal <text>Give it a standing objective.
    #ai persona [text]Show or set its personality.
    #ai trust [name]Trust a player, or list trusted players.
    #ai untrust <name>Stop trusting a player.
    #ai deny <command>Forbid a # command.
    #ai allow <command>Allow it again.
    #ai extra <json|none>Add JSON to every API request.
    #ai forget [all|text]See or wipe its long-term memory.
    #ai clearForget the current conversation.

    Saved in baritone/ai.json and baritone/ai_memory.json.
