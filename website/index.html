    01SEED MAP

    Every structure. Checked, not guessed.

    Most seed maps stop at “this chunk could have a village.” #seedmap keeps going. For every candidate around you it runs Minecraft's own structure generation offline: biome checks, terrain checks, jigsaw assembly. Only the ones that would really generate make it onto the map.

    With JourneyMap installed they land on the fullscreen map with real footprints, hover details, per-family layers and right-click go here. Without it you get the list in chat with clickable coordinates.

    On a server, give it the seed once with #seedinput. It's checked against the seed hash the server sends when you join, so a wrong seed gets refused instead of quietly drawing the wrong map. Each server keeps its own.

    02MACROS

    Macros that wait for the server, not a timer.

    97 action types. Packet gates and bursts, server-tick sync, container click sequences. Waits on a GUI, a chat line, a sound, an entity, a slot change or a teleport. Branches, labels, variables, finally blocks.

    Build them in the editor, bind them to a key, and run them across accounts with LAN sync. Addons can register their own actions and conditions.

    03PATHING

    Baritone lives inside.

    No second mod to install. #goto, #mine, #follow, #elytra, #build, the native nether pathfinder, all in the same jar.

    While it walks you see the plan in the world: a guide line to the next step, the current and queued path, the blocks it's about to break or place, and a beacon on the goal. That's what the map at the top of this page is doing.

    Or give the controls away: #ai hands the player to a language model that reads chat and plays by running Baritone commands. Bring your own key and endpoint.

    04PACKETS

    See the wire.

    A packet log, a packet canceller, a custom payload sender, an NBT viewer, delay and burst gates. When a dupe works you'll know which packet did it, and when it doesn't you'll know which one the server threw away.

    It's a debugging client first. Test on servers you own or have permission to break.

    05PRIVACY

    Servers see less.

    Servers fingerprint clients by the channels they register, the translation keys they resolve and how they answer resource-pack probes. DIH filters mod channels, answers translation-key probes with vanilla strings and keeps its own packs out of resource-pack responses.

    Built on ideas from OpSec. It raises the bar. It isn't a cloak.

    Questions people actually ask

    Will I get banned?

    On servers with an anticheat, some modules will flag. The client says so in the module description when it knows (AntiHunger, for one). Use it where you're allowed to.

    Is it a virus?

    The whole thing is open source under GPL-3.0. Read it, build it yourself with gradlew build -Prelease, and compare the SHA-256 above with what you downloaded.

    I used XINYUAN / Autism Client. Where are my settings?

    On first launch DIH copies your old accounts, proxies, macros and config over to the new names. The old files stay where they were, in case you go back.

    Do I need JourneyMap?

    No. It's optional. With it, the seed map and heatmap draw on the fullscreen map with toolbar toggles and right-click actions. Without it everything still works and results go to chat.

    Which Minecraft versions?

    26.2 only, for now. Each release is built for one version.
