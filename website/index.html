Features

#seedmap

Every structure, checked.

Runs the real worldgen for your seed and draws it on JourneyMap.

.macro

Macros that wait for the server.

97 actions, synced to server ticks, not timers.

#goto

Baritone, built in.

Pathing, mining, elytra, and an AI that plays through it.

BETA 5.1-beta.3

Name an item.
It gets it.

#acquire iron_pickaxe works out the whole chain: trees, tools, ore, a furnace, mobs if it needs them. Then it runs it, and re-plans when something goes wrong.

  • Counts what you already carry
  • Eats when you're hurt, and fetches food if you have none
  • Only hunts the mob it needs, never pets or villagers
  • #ai can use it: “get me an iron pickaxe”
  • #stop cancels it, like any Baritone task

Install

  1. 1Install Fabric Loader 0.19.3+ and Fabric API. Java 25.
  2. 2Put DIH Client and JourneyMap in your mods folder.
  3. 3In game, Right Shift opens modules. .help and #help list commands.
