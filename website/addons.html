Built into DIH

Shipped inside the client jar from 5.1 beta 7 and off by default. Turn them on in Addons; no internet needed.

Install an addon

  1. 1In DIH, open Addons and click Browse Online. Needs 5.1 beta 7 or newer.
  2. 2Click a card, then Install twice. DIH downloads it, checks the SHA-256 and puts it in mods.
  3. 3Restart Minecraft. Uninstall works the same way; the jar is deleted when the game closes.

Addons run code inside your game with the same access as the client itself. Only install ones you trust. A listing here means a maintainer read it, not that it is risk-free.

Publish your addon

Listing is free. You add one small JSON file by pull request; once it is merged it shows up here and in every player's in-game browser on their next refresh, with no client update.

  1. 1Build from a template: python addon-templates/addon-toolkit.py setup --template minimal, then ./gradlew build.
  2. 2Release the jar on a public GitHub repo. One jar per Minecraft version, same addon version.
  3. 3Describe it: python registry/registry.py add --jar … --source … --jar-url … --summary "…". Add a 16:9 card image with --image.
  4. 4Open a pull request with registry/addons/<id>.json and website/addons.json. CI checks it; a maintainer reviews the source.
